1
Add the visual

Get Sales Territory Balancer from AppSource, or import the file via More visuals.

2

3

5

Workload ÷ hours per salesperson, per area — 6.4, not "6 or 7".

Key Benefits
Balanced, with a hard limit

No territory above the hours you set; travel time included.

Land borders and islands

Areas never cross a gulf or the sea.

Whole postal codes

Bind the postal code and each code goes to one salesperson.

Private by design

Outlines travel inside the visual; customer locations stay in the report.

Tips & Best Practices
✓Set the road factor for your country: distances are straight lines times it.
✓Assign by postal code? Bind Postal code so codes are not split.
✓Click an area to see its territories and filter the rest of the report.
✓Try "what if 120 h?" in the bar: same data, same result, every time.
✓Travel time is a planning estimate — it does not plan routes or visits.
