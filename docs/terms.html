5. What the result is, and is not

The visual is a design and simulation tool. It computes a balanced assignment and shows it; it does not, and cannot, write that assignment back into your data model. Power BI custom visuals have no way to modify the dataset they read. To carry a territory plan into your model, use the CSV export or the assignment you see on screen, and load it the way you load any other data.
  • Distances are straight-line, multiplied by the road factor, which you set for your country. The visual has no network access, so it cannot query a routing service; travel is an estimate for planning, not a route.
  • Territories never exceed the hours you set. Some end short — a remote area or a small island may need only a fraction of a salesperson — and are shown as such.
  • How every figure is computed, with its assumptions and limitations, is published in the Methodology.
  • The result is deterministic. The same data with the same parameters produces the same territories every time, on any machine.
  • You are responsible for validating a territory plan before acting on it.
